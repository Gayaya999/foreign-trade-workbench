# 外贸工作台 · Foreign Trade Workbench

面向外贸企业与 SOHO 的对话式工作台原型。先建立一份共用企业档案，再分别整理海外客户开发与海外社媒内容任务。

**当前为纯前端、本地规则引导的交互原型。** 尚未接入大模型、真实客户搜索、邮件发送或社媒发布，保存任务不会自动执行这些动作。

## 主要功能

- **企业档案**：通过对话逐步录入企业、产品、供货能力、目标市场与品牌偏好，也可打开表单直接编辑、核对和保存。
- **客户开发**：基于企业档案副本，独立整理目标市场、买家类型、产品范围和排除条件，保存任务草稿。
- **社媒内容**：基于企业档案副本，独立整理受众、平台、语言与内容方向，无需先完成客户开发。
- **状态面板**：展示当前档案或任务状态；桌面可收起，窄屏以抽屉形式查看。
- **本地保存**：保留档案、任务和三个工作区各自的对话，支持 JSON 导入与导出。
- **资料附件**：通过 IndexedDB 在本机保存附件原文件；JSON 导出仅包含附件引用与元信息，不包含附件原文件。

界面采用灰白平面背景、左侧模块导航和独立的对话／状态区域，支持窄屏使用。

## 本地运行

无需构建或安装前端依赖。可直接打开 `index.html`；为了获得稳定的本地存储与附件体验，建议在项目目录使用静态服务器：

```bash
python3 -m http.server 8000 --bind 127.0.0.1
```

然后访问 <http://127.0.0.1:8000/>。

也可克隆仓库后运行：

```bash
git clone https://github.com/Gayaya999/foreign-trade-workbench.git
cd foreign-trade-workbench
python3 -m http.server 8000 --bind 127.0.0.1
```

```text

企业档案工作台.html         完整页面，包含样式、状态和交互逻辑
README.md                  使用说明

tests/                     交互测试
```

目前交付为单 HTML 文件，方便离线查看和直接演示。界面按企业档案、客户开发、社媒内容三个模块组织，并未拆分为独立的前端构建包。

## 检查与测试

运行页面不需要 Node.js；如需运行交互测试，请使用 Node.js 24 或更新版本：

```bash
npm ci --ignore-scripts
npm test
```

测试覆盖三个工作区切换、企业信息整理、档案与任务编辑抽屉、对话隔离和会话恢复。这些本地检查不替代真实浏览器的视觉验收。

## 数据与能力边界

- 档案、任务、对话存储在当前浏览器的 `localStorage`，附件保存在该来源的 IndexedDB 中；当前页面没有后台同步服务。
- 不同浏览器、端口、域名或 `file://` 地址可能使用不同的存储空间。切换访问方式前可先导出 JSON，并单独备份附件。
- 对话整理采用本地规则，支持范围有限；自动识别后的事实应由用户核对。
- 每个任务保留自己的企业档案副本。修改共用档案不会覆盖已有任务，新建草稿可以引用新的档案版本。
- 页面中的进度表示需求整理或草稿保存状态，不表示已经执行海外搜索、生成真实 AI 内容、发送邮件或发布内容。
